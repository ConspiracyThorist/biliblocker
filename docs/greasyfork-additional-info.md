**B站推荐流屏蔽器** —— 在推荐数据抵达页面之前就把它删掉，不是事后遮住：没有留白、没有闪烁。
两件事同时做：拦截**搬运知乎热榜**的视频，以及按你自己的**规则**过滤推荐流与评论区。

## 功能

- **知乎搬运拦截**：内置题库每日同步（600+ 条，持续增量），标题归一后做相似度匹配，命中即从接口响应里摘掉
- **规则过滤**：关键词（`/正则/`、`title:` / `up:` / `part:` 作用域）、UP 名、UID、BV 号、分区、播放/点赞/时长阈值、营销号低赞率、广告卡、直播卡
- **评论区过滤**：关键词、昵称、等级、默认头像、AI 总结机器人、召唤 AI、带货导流、纯表情、纯 @；命中折叠成可展开的灰条
- **评论区大图预加载**：图片滚进视口就缓存原图，点开不再转圈（可在设置里关闭）
- **白名单优先**：标题 / UP / 分区 / UID 命中白名单永不屏蔽
- **一次点击**：卡片上、播放页里都能「屏蔽此 UP」；拦截记录里能「放行」
- **规则导入**：可直接导入 biliHoyoFairy 导出的 JSON，联网维度会明确列为跳过

## 使用

安装后刷新 B 站，右下角出现胶囊，点开是四段面板：**概览 / 拦截 / 规则 / 设置**。

规则页顶部输入框会自动识别类型：

| 输入 | 添加到 |
|---|---|
| `BV1xx411c7mD` | BV 号（单视频） |
| `7001` | UID |
| `/震惊[！!]{2,}/` | 正则关键词 |
| `送十连` | 标题关键词 |
| `up:某个UP` | 只匹配 UP 名 |

**强度三档**：保守（0.86，默认，只拦原样搬运）/ 标准（0.78）/ 激进（0.66）。只影响知乎题库那一路，关键词与 UP 规则不受影响。

## 常见问题

**装上没效果？**
先确认**只装了一个版本**（别再同时装 Chrome 扩展），两者会各 hook 一遍接口，判两次、记录重复。再看面板「概览」里题库条数与累计拦截数是否在变。

**照搬的视频没被拦？**
默认保守档只拦原样搬运；改写过的会被放过。加关键词规则比调低阈值更可控。

**误拦了正常视频？**
记录里点「放行」加白名单，或把强度切回保守。

**题库为什么不涨？**
题库由数据仓每天跑一次增量：热榜约 30 条，去重后实际新增十几到二十条，所以是缓慢爬升。

**规则同步失败？**
多为远端 CDN 不可达，脚本会继续用上次成功的数据；面板里能看到具体错误。

**预加载费流量吗？**
只在你滚到图片附近时预取原图，并发上限 2；可在「设置 → 通用」关掉。

## 兼容性

主要在 Chrome / Edge 的 Tampermonkey 上验证；Firefox 与其他脚本管理器可用但未逐一验证。与同类净化脚本同时使用时，可能互相干扰卡片样式，建议只留一个。

## 隐私

- 题库、规则、命中记录全部保存在本地（`GM_setValue`），**不上传**
- 不读取 cookie，不申请账号相关权限
- 仅当你手动拉黑 UP 且开启「匿名贡献」时，才上传 UP 编号与昵称（不含任何账号信息，可关闭）
- 网络请求仅涉及：B 站页面与接口、知乎热榜接口、题库/UP 库的 CDN、投稿端（仅贡献开启时）
