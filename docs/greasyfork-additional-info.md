# BiliBlocker 附加信息（脚本市场用）

## 这是什么

B 站推荐流屏蔽器。在推荐数据抵达页面之前就把它删掉——不是事后遮住，所以没有留白、没有闪烁。
两件事同时做：拦截**搬运知乎热榜**的视频，以及按你自己的**规则**过滤推荐流与评论区。

## 功能

- **知乎搬运拦截**：内置题库每日同步（当前 600+ 条，持续增量），按标题归一后做相似度匹配
- **规则过滤**：关键词（支持 `/正则/` 与 `title:` / `up:` / `part:` 作用域）、UP 名、UID、BV 号、分区、
  播放量 / 点赞 / 时长阈值、营销号低赞率、广告卡、直播卡
- **评论区过滤**：关键词、昵称、等级、默认头像、AI 总结机器人、召唤 AI、带货导流、纯表情、纯 @；
  命中折叠成可展开的灰条，白名单（UP 主 / 置顶 / 自己）优先
- **评论区大图预加载**：图片滚进视口就缓存原图，点开不再转圈（可在设置里关闭，会省流量）
- **白名单优先**：标题 / UP / 分区 / UID 命中白名单永不屏蔽
- **一次点击**：卡片上、播放页里都能「屏蔽此 UP」，拦截记录里能「放行」
- **规则导入**：可直接导入 biliHoyoFairy 导出的 JSON，联网维度会明确列为跳过
- **稳定**：配置写入带版本与自动备份，多标签页不会互相覆盖

## 使用

安装后刷新 B 站，右下角出现胶囊；点开是四段面板：**概览 / 拦截 / 规则 / 设置**。

规则页顶部输入框会自动识别类型：

| 输入 | 落到哪 |
|---|---|
| `BV1xx411c7mD` | BV 号（屏蔽单视频） |
| `7001` | UID |
| `/震惊[！!]{2,}/` | 正则关键词 |
| `送十连` | 标题关键词 |
| `up:某个UP` | 只匹配 UP 名 |

播放页打开面板，顶部会出现「正在看」，可以一键屏蔽当前 UP。

## 常见问题

**装上之后没效果？**
先确认**只装了一个版本**：如果同时装了 Chrome 扩展，两者会各自 hook 一遍接口，判两次、记录重复、开销翻倍。再看面板「概览」里题库条数与累计拦截数是否在变。

**题库数量不增长？**
题库由项目的数据仓每天跑一次增量：热榜约 30 条，去重后实际新增十几到二十条，所以是缓慢爬升。

**照搬的视频没被拦？**
默认「保守」档只拦原样搬运。设置里可切到「标准」或「激进」，代价是误伤概率上升；也可在规则里加关键词，比调低阈值更可控。

**卡片被误拦？**
记录里点「放行」会加进白名单；或把强度切回「保守」。

**评论区图片预加载耗流量吗？**
只在你滚到那张图附近时预取原图，并发上限 2；不想用可以在「设置 → 通用」里关掉。

**规则同步失败？**
多为远端 CDN 不可达，脚本会继续用上一次成功的数据；面板里能看到具体错误。

## 兼容性

主要在 Chrome / Edge 的 Tampermonkey 上验证；Firefox 与其他脚本管理器可用但未逐一验证，遇到问题欢迎反馈。

## 隐私

- 题库、规则、命中记录全部保存在浏览器本地（`GM_setValue`），不上传
- 只有手动拉黑 UP 且开启「匿名贡献」时，才把 UP 编号与昵称提交到投稿端，不含任何账号信息，可关闭
- 不读取 cookie，不申请账号相关权限
- 网络请求仅涉及：B 站页面与接口、知乎热榜接口、题库/UP 库的 CDN、以及投稿端（仅在贡献开启时）
