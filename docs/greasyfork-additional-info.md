**B站推荐流屏蔽器** —— 在推荐数据抵达页面之前就把它删掉，所以没有留白、没有闪烁。
两件事同时做：屏蔽**搬运知乎热榜**的视频，以及按你自己的**规则**过滤推荐流与评论区。

## 功能

**屏蔽搬运**
- 内置题库每日自动同步（600+ 条，持续增长），按标题相似度匹配，改写、删减、加前后缀也能认出

**按规则过滤**
- 关键词：普通词、`/正则/`、`title:` / `up:` / `part:` 作用域
- 对象：UP 主名、UID、BV 号、视频分区
- 数值：播放量、点赞数、时长区间；营销号低赞率识别
- 卡片类型：广告卡、信息流直播卡

**评论区**
- 屏蔽：关键词、昵称、等级过低、默认头像水军、AI 总结机器人、带货导流、纯表情、纯 @
- 处理方式：折叠成一行可展开的灰条，不直接删除，想看点开就有
- 白名单：UP 主本人、置顶、你自己，永远不折叠
- 评论区大图预加载：滚到附近就把原图缓存好，点开不再转圈（可关）

**其它**
- 白名单优先：标题 / UP / 分区 / UID 命中白名单的永不屏蔽
- 一次点击：卡片上、播放页里都能「屏蔽此 UP」；拦截记录里能「放行」
- 规则导入：支持导入 biliHoyoFairy 导出的规则 JSON

## 安装

1. 浏览器装好 **Tampermonkey**（或 Violentmonkey）
2. 在本页点「安装此脚本」
3. 刷新 B 站，右下角出现胶囊即生效

Chrome / Edge 如果提示脚本未运行，需要到 `chrome://extensions` 打开「开发者模式」，并允许用户脚本运行。

> 用过 Chrome 扩展版的话，**先在 `chrome://extensions` 里关掉它**。两个版本各拦一遍，会重复判定、记录翻倍。

## 使用

点右下角胶囊展开面板，四段：

| 页面 | 用途 |
|---|---|
| **概览** | 累计拦截、来源分布、最近拦截、题库状态 |
| **拦截** | 全部记录，可就地「放行」；标题鼠标悬停展开全文 |
| **规则** | 快速添加、分组管理、数值阈值、评论区开关 |
| **设置** | 强度档位、题库同步、导入导出 |

规则页顶部输入框会自动识别类型：

| 输入 | 添加到 |
|---|---|
| `BV1xx411c7mD` | BV 号（单视频） |
| `7001` | UID |
| `/震惊[！!]{2,}/` | 正则关键词 |
| `送十连` | 标题关键词 |
| `up:某个UP` | 只匹配 UP 名 |

**强度三档**：保守（0.86，默认，只拦原样搬运）／标准（0.78）／激进（0.66）。
只影响知乎题库那一路；关键词和 UP 规则不受影响。

## 注意事项

- **别和 Chrome 扩展版同时装**，会重复判定
- 规则加多了建议在「设置 → 数据」里导出备份，换设备时导入即可
- 删掉规则或关掉开关后，已经隐藏的卡片会立即恢复，不用刷新
- 播放页点「举报」等 B 站弹窗时，胶囊会自动让位，不会挡住按钮

## 常见问题

**装上没效果？**
先确认只有这一个版本在跑，再看「概览」里题库条数、累计拦截数是否在变。默认保守档只拦原样搬运。

**照搬的视频没被拦？**
默认档只认原样搬运，改写过的会放过。加关键词比调低强度更可控。

**误拦了正常视频？**
记录里点「放行」加白名单，或把强度切回保守。

**题库为什么不涨？**
题库每天增量同步一次：热榜约 30 条，去重后实际新增十几到二十条，是缓慢爬升。

**同步失败？**
多为 CDN 不可达，脚本会继续用上次成功的数据，面板里能看到原因。

## 兼容性

主要在 Chrome / Edge + Tampermonkey 验证。Firefox 与其他管理器可用但未逐一验证。
和同类净化脚本同时用时，可能互相干扰卡片样式，建议只留一个。

## 隐私

- 题库、规则、命中记录只存在本地，**不上传**
- 不读取 cookie，不申请账号相关权限
- 只有你手动拉黑 UP 且开启「匿名贡献」时，才上传 UP 编号与昵称（不含任何账号信息，可关闭）
